# Poké Etymology

A mobile-first multilingual Pokédex focused on how Pokémon names work: roots, puns, cultural references, native-speaker experience, localization choices, and effort value yields.

## Current preview

The first public preview contains National Pokédex **#001–#025** with:

- English, French, Japanese, and Japanese romanization
- EV yields
- compact etymology notes for all three languages
- confidence labels
- cross-language localization comparisons
- search by any included language
- a responsive interface inspired by the raw four-tone visual language of Generation I handheld Pokémon games

The preview deploys to GitHub Pages from `main`.

## Research status

This is an early research seed rather than a finished encyclopedia. Etymologies are marked with confidence levels so plausible interpretations are not presented as settled fact.
