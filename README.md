# Poké Etymology

A mobile-first Pokémon language and completion companion.

## Current release

- all 151 Generation I species in English, French, Japanese, and Japanese romanization
- types and EV yields generated from structured source data
- reviewed comparative etymologies for #001–#025; remaining entries are clearly marked for research
- separate living-dex guide pages, beginning with FireRed / LeafGreen
- no sprites and no attempt to duplicate a general-purpose Pokémon encyclopedia

See [PROJECT_GOALS.md](PROJECT_GOALS.md) for the product boundaries and order of work.
